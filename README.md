# General info

I have created a HTML page to allow the user to enter an amount and be given the optimum change once the enter key has been pressed. 

Just open the index.html in your browser and enter the amount you wish to receive change for and press the enter key.

I have specified my tests within the folder `tests`
just open `tests/index.html` to view the test results.

The tests are specified in `tests.js` and I have used Jasmine as my testing suite following TDD practices. I have used the example valid/invalid inputs as a starting point and added a few of my own test cases.

# Install for dev

1. run `bundle install`
2. run `npm install`

# Running dev configurations

3. run `grunt`
